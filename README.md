# Vida de estagiário
Abaixo será apresentado os principais pontos que vamos abordar nessa jornada conjunta.

## SQL:
### DDL - (Data Definition Language):
- Trata da definição da estrutura do banco de dados.
  
### DQL - (Data Query Language)
- É utilizado para consultas e recuperação de dados.

### DML - (Data Manipulation Language)
- Usado para manipular dados dentro das tabelas.
  
### DCL - (Data Control Language)
- Controla o acesso e permissões dos dados.

### TCL - (Transaction Control Language)
- Gerencia transações e garante a integridade dos dados.
  
### Comandos:
| Comando         | Subconjunto SQL|
|-----------------|----------------|
|```DROP```       | DDL            |
|```CREATE```     | DDL            |
|```INSERT INTO```| DML            |
